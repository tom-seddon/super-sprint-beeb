# Brief - room for Phase 5 (a RAM hunt)

> **Status: BUILT (2026-11-03), three levers and a fix; not merged.** Branch `phase5`. Phase 5's step 2
> (`docs/brief-phase5.md`): main RAM had 103 bytes free in the play build, and the loader, the front end
> and the game's rules between races are still to come.
>
> Figures say **MEASURED** (a build's listing or a tool run, named), **COUNTED** (off the source or a listing)
> or **PROJECTED** (arithmetic on top).

## 1. The memory map was wrong first

`tools/memmap.py` gave each source file the bytes from its INCLUDE to the next INCLUDE. A file that includes
a constants-only file (the generators' lists) at its top lost all its bytes to it: `objects.6502`'s 1,600
bytes of code showed as `gen/objects.6502`'s, `hud.6502`'s 369 as `gen/font.6502`'s, `cars.6502`'s as
`gen/prio.6502`'s. Phase 5's brief built its "lever 1" on that ("1,600 bytes of per-track tables in main
RAM"): there were no such tables. Fixed: a file whose every line is `Name = ...` isn't a mark.

## 2. The ledger (MEASURED, `tools/all_tracks.sh` and the play build, before)

For one build that races every track, a region's room is its smallest over the tracks.

| Region | Free, before (least over the tracks) | Who can use it |
|---|---|---|
| Main RAM's code | 103 (every track) | anything |
| The fourth bank, `&9000`-`&BFFF` | 1,828 (every track) | code run with the logic's bank and ANDY in: the logic, and Phase 5's rules that touch its state |
| The fourth bank's first 4K | 4,096 (D16) | code run with ANDY out: the front end (Phase 5's brief) |
| Shared (`&3070`-`&3EFF`, both screens) | 768 (tracks 4 and 6) | read-only data and code that doesn't modify itself, read whatever's paged |
| ANDY | 237 (track 8) | mask B and the logic's state |
| The cars' bank | 422 (track 6) | the car plotter's |
| The objects' bank | 2,491 (track 5) | the objects' plotters' |
| GameVars | 174 | variables below `&3000` |
| `&0900`-`&0AFF` (D26, added during the hunt) | 512 | anything that survives a load: Tom's, from the Master Reference Manual, checked across DFS loads |
| Zero page | `&5A`-`&7B` | |

## 3. The levers, costed

What's in main RAM (COUNTED, the listing): the IRQ 101, the frame loop 358, the HUD 369 (its font 120),
the objects' copier 1,600 (it pages three banks and patches its own operands), and 4,616 of the race's
logic: `race.6502` 2,012, `human.6502` 780, `random.6502` 470, `arith.6502` 401, `lgen/tables` 183, the
keys 97, the sound 694 (its IRQ half must stay). Every caller of the logic's routines (`race`, `human`,
`random`, `arith`, the tables) is the logic itself, run with the fourth bank and ANDY paged in
(COUNTED: each one's callers in the listing). So each can move into the fourth bank at no cost in cycles;
the question is only which region pays.

## 4. What landed

Main RAM 103 -> 780 free on every track (MEASURED, `tools/all_tracks.sh`, 2026-11-03):

| Region (least over the tracks) | Before | After |
|---|---|---|
| Main RAM's code | 103 | **780** |
| The fourth bank | 1,828 | 1,244 |
| Shared | 768 | 648 |
| ANDY, the cars' bank, the objects' bank | 237, 422, 2,491 | the same |

The hazard race (track 5, race 17, `make check TRACE=logic4`, MEASURED before and after in jsbeeb 2.18.0):
work cycles a frame, mean 32,871 -> 32,863; frames over a TV frame 116 -> 116; fields repeating a frame
5 -> 6, in the same 5 frames (one of them now finishes just past its blank's end); all 2,240 frames match
the model. The suite (`tools/suite.sh`, 19 checks) passes: see the commit.

**Mistake**: my first font assert asked for the whole font in one page; tracks 2, 3, 7 and 8 failed to
assemble, caught by the suite's all-tracks run, not the race checks. `hud_char` needs only each glyph in one
page: aligned to 8 now.

**Also found**: `&0400`-`&07FF` was missing from the map, though it's the game's (the car plotter's tables, 1,024,
full), as were `&2A00`-`&2DFF`'s sections; `SKIP 4 * MaxObjEvents` counted as 1 byte, and ScreenVars' extent
was Shared's. All fixed in `tools/memmap.py`, which now lists every section.

**Open**: the fourth bank (1,244) is where Phase 5's rules between races that touch the logic's state go
(the bonuses, the elimination, the upgrades); lever 5 waits on their size.
